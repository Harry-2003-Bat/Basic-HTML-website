# Basic HTML Website

A foundational web project developed to fulfill the **Basic HTML Website** project challenge from [roadmap.sh](https://roadmap.sh/projects/basic-html-website).

## 📌 Project Overview
This project focuses on writing clean, semantic, and standards-compliant HTML5 without any external CSS or JavaScript dependencies. The primary objective is to build a rock-solid understanding of document object flow, web accessibility fundamentals, and content hierarchy.

## 🚀 Features
- **Semantic Structure:** Proper use of semantic elements (`<header>`, `<nav>`, `<article>`, `<section>`, `<footer>`) for better readability and SEO.
- **Multi-page Navigation:** Functional navigation bar linking Home, About, Projects, and Contact pages.
- **Forms & Inputs:** Standard contact form utilizing built-in HTML5 validation attributes (`required`, `type="email"`, etc.).
- **Media & Tables:** Integrated tabular layouts and properly referenced media with descriptive `alt` attributes for accessibility.

## 🛠️ Built With
- Pure **HTML5** (No external CSS or JS)
